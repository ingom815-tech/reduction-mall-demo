1d:T2a96,<h1>AM0017 스팀트랩 방법론 정리</h1>
<ul>
<li>원문: <code>〔원문 보관함〕</code> (21쪽)</li>
<li>구판: <code>UNFCCC_CDM_AM0017_Steam_traps_condensate_v1.0_superseded.pdf</code></li>
<li>정식 명칭: AM0017 &quot;Steam system efficiency improvements by replacing steam traps and returning condensate&quot;</li>
<li>판: Version 02, 2005-06-21부터 유효, Active, 대규모, Sectoral scope 3</li>
<li>기반 사업: 중국 푸순 정유공장 사례(NM0017-rev)</li>
<li>수식 1·4·8은 PDF 이미지로 직접 확인함 [원문 확인]</li>
<li>정리일: 2026-10-20</li>
</ul>
<h2>1. 적용 조건 (Applicability)</h2>
<ol>
<li>스팀트랩 교체·수리, 그리고/또는 응축수 회수로 스팀 효율을 개선하는 사업</li>
<li><strong>스팀이 사업장 안의 화석연료 보일러에서 생산될 것</strong> → 구매 스팀은 적용 대상이 아님</li>
<li>그 나라에서 스팀트랩 정기 정비나 응축수 회수가 <strong>일반적 관행이 아니고 법적 의무도 아닐 것</strong></li>
<li>비슷한 공장 <strong>5곳 이상</strong>의 스팀트랩 상태·응축수 회수 자료를 구할 수 있을 것</li>
</ol>
<h2>2. 추가성 (4단계)</h2>
<ol>
<li><strong>비교군 조사</strong>: 사업 공장과 비슷한 공장 5곳(같은 업종, 비슷한 스팀 용량, 같은 지역, 비슷하거나 최신 연식)을 조사함. 다음 중 하나라도 해당하면 추가성 없음:<ul>
<li>비교군 평균 트랩 고장률이 사업 공장보다 5%p 넘게 낮음</li>
<li>비교군 평균 응축수 회수율이 사업 공장보다 5%p 넘게 높음</li>
<li>사업 공장에 정기 트랩 정비 프로그램이 이미 있거나 계획되어 있음</li>
</ul>
</li>
<li>법·제도 요구사항 검토</li>
<li>장벽 분석: 투자·기술·관행 장벽</li>
<li>CDM 등록이 장벽을 넘게 해 주는지 설명</li>
</ol>

<h3>Step 2-2. 스팀 절감량 (식 4)</h3>
<pre><code>ΔL_steam traps,y [t] = [ Σ L_t,0 (BT) + Σ L_t,0 (LK) + Σ L_t,0 (RC) − Σ L_t,y ] ÷ 1000
</code></pre>
<ul>
<li>기준선 손실 L_t,0을 계산할 때는 운전시간을 보수적으로 잡음: 사업 후 운전시간이 사업 전보다 짧으면 사업 후 값을 씀.</li>
<li>사업 후 손실 L_t,y는 <strong>모니터링 조사에서 고장으로 판정된 트랩의 손실</strong>임. 조사에서 고장이 발견되면 &quot;직전 조사 이후 계속 고장이었다&quot;고 봄.</li>
</ul>
<h3>Step 3. 응축수 회수 (식 5~7) — 1단계 범위 밖</h3>
<ul>
<li>상대 절감률 l = (h_condensate − h_makeup) × m_condensate ÷ (h_steam × m_steam)</li>
<li>사업 전 2년 평균과 비교하고, 절대 차이를 넘지 않게 제한함.</li>
</ul>
<h3>Step 4. CO2 감축 (식 8)</h3>
<pre><code>ER_steam,y [tCO2] = EF_CO2,fuel [kgCO2/kJ] × (ΔL_steam traps,y + ΔL_condensate,y) × h_steam,y [kJ/kg] ÷ ε_boiler
</code></pre>
<ul>
<li><strong>CO2만 셈.</strong> CH4·N2O는 무시함.</li>
<li><strong>h_steam 전체 엔탈피를 씀.</strong> 급수 엔탈피를 빼지 않음.</li>
<li>보일러 효율 ε은 다음 셋 중 <strong>가장 높은 값</strong>을 씀(보수적).<ol>
<li>사업 전 실측</li>
<li>모니터링 중 실측</li>
<li>제조사 값</li>
</ol>
</li>
<li>연료 순발열량(NCV)과 배출계수는 국가 자료를 우선하고, 없으면 IPCC 기본값을 보수적으로 씀.</li>
</ul>
<h3>Step 5~7. 전력 변화와 순감축</h3>
<ul>
<li>응축수 회수 펌프·처리로 늘어난 전력과, 보충수 펌핑이 줄어든 전력을 반영함(식 9~12).</li>
<li>순감축 = 스팀 절감 감축 + 전력 변화(식 13).</li>
<li>누출(leakage)은 계산하지 않음.</li>
</ul>

<h2>5. 우리 설계에 주는 의미</h2>
<ol>
<li><strong>감축량은 제품 시험값이 아니라 &quot;현장 트랩 조사 결과&quot;에서 나옴.</strong> 기준선은 고장 트랩(BT·LK·RC)의 오리피스·압력·용도·운전시간으로 계산함. 그래서 PHV의 0.0047 kg/h 같은 제조사 시험값과 압력 범위 문제(D9)가 계산에 필요 없어짐.</li>
<li><strong>&quot;예상&quot;의 의미가 분명해짐.</strong> 1년차 예상 = 교체한 트랩이 다음 조사까지 정상 작동한다고 가정할 때의 기준선 손실 전체. 실측(MRV)은 다음 조사에서 발견된 고장 트랩 손실을 뺀 값임.</li>
<li><strong>구매 스팀 고객은 대상이 아님.</strong> 적용 조건 2번에 따라 D10은 &quot;1단계는 자체 화석연료 보일러 고객만&quot;으로 정리됨.</li>
<li><strong>보일러 효율은 세 값 중 가장 높은 것.</strong> 고객 입력란에 그렇게 안내함.</li>
<li><strong>식 8은 h_steam 전체를 씀.</strong> 기존 잠정 산식의 (h_steam − h_feed)와 다름. 방법론 기준 결과와 &quot;공학적 참고값&quot;을 구분해야 함.</li>
<li><strong>CO2만 셈.</strong> 국가 세트(AR5 3가스)와 다르므로 방법론 기준 결과는 CO2-only로 계산하고 그렇게 표시함.</li>
<li><strong>추가성 부담이 큼.</strong> 비교군 5곳 조사가 필요함. 외부사업 판정에서 &quot;조건 충족 시 가능, 필요: 비교군 5곳 조사, 정기 정비 프로그램 없음 확인&quot;으로 안내함.</li>
<li><strong>유지보수 쟁점에 대한 단서.</strong> 방법론 자체가 &quot;정기 정비가 관행이 아닌 경우&quot;를 전제로 교체·수리를 인정함. 국내 외부사업 지침의 &quot;유지보수 제외&quot; 조항과의 관계는 여전히 확인이 필요함(R9).</li>
<li><strong>오리피스 지름이 핵심 입력임.</strong> 영인 제품 데이터에는 없어도 되지만, 고객 기존 트랩의 오리피스 크기는 진단 결과로 받아야 함.</li>
</ol>
<h2>6. 검산 예시 (구현 테스트 벡터 후보)</h2>
<ul>
<li>조건: Blow-thru, Process 용도, 오리피스 1/8 inch, 입구 0.7 MPaG, 대기 배출, 연 8,000 h<ul>
<li>P_in = (0.7 + 0.101325) × 145.038 = 116.2 psia</li>
<li>P_out은 대기(14.7 psia)로 P_in/2보다 작으므로 P_out = P_in/2 = 58.1 psia</li>
<li>√((116.2 − 58.1) × (116.2 + 58.1)) = √(58.1 × 174.3) ≈ 100.6</li>
<li>CV = 22.1 × 0.125² = 0.345</li>
<li>시간당 = 1 × 0.9 × 0.345 × 100.6 ≈ 31.3 lbs/h ≈ 14.2 kg/h</li>
<li>연간 L ≈ 14.19 × 8,000 ≈ 113.5 t 스팀</li>
</ul>
</li>
<li>이 값은 손으로 한 계산임. 구현 후 같은 값이 나오는지 테스트로 고정함(반올림 차이 허용 범위를 함께 정함).</li>
