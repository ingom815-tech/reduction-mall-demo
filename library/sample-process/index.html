3. 판단한 점

3.1 분류 차이

  • 중기부 공고(p.7)의 '공정최적화형'에는 FEMS와 펌프 인버터가 직접 들어 있지 않음. FEMS 계열은 '배출진단형 에너지관리시스템', 인버터는 '에너지절감형'임. 압축공기 지능제어만 공정최적화형 예시에 들어 있음.
  • 사이트 분류는 요청대로 '공정 최적화형'으로 두되, FEMS와 인버터 설명(description)에 공고상의 분류를 적어 둠.

3.2 펌프 인버터의 relatedEquipment

  • []로 둠. 근거: UMP 18장은 공기압축기를 별도 프로토콜 대상으로 빼고(p.1), 녹색분류체계도 '인버터(팬·펌프)'와 '인버터제어형 압축기'를 다른 항목으로 둠(p.173). 공단 2024 가이드라인도 압축공기 시스템(2.1)과 전동기·응용기기(2.2)를 나눔.

3.3 일부러 넣지 않은 숫자

  • 공단 21개 품목 p.4의 공기압축기 통합제어 투자경제성 예시(75HP 정속형 4대, 연 300일·가동률 70% 가정, 약 28% 절감, 회수 3.6년). 원문이 "참고사항으로 실제 절감효과는 다를 수 있음"이라고 적었고, 제품 화면에서 약속처럼 보일 수 있어 JSON에 넣지 않음. 필요하면 "공단 참고 예시(가정 조건 포함)"로만 표시할 것.
  • 공단 21개 품목 p.6 IoT 스마트에너지 통합제어시스템의 "평균 10% 절감"은 중소형 기축건물(대학·관공서) 예시라 공장 FEMS 근거로 쓰지 않음.
  • UMP 22장 누설 계산 예시(75 hp, 58 SCFM → 43,883 kWh)와 CCAF 값은 계산식 설명으로만 언급함.
  • 녹색분류체계 산업 (8)의 "내용연수 × 2.9%" 기준은 설비별 판정이 필요해 넣지 않음.

4. 확인하지 못한 것

  • 국내 공식 FEMS 사양 기준: FEMS 자체의 기능·성능 기준(구성요소, 데이터 항목, 인증 제도)을 정한 공식 문서는 보관 원문에 없음. 이번 FEMS 사양은 효율시장 조성사업의 계측 기준과 M&V 옵션 C 기준을 빌려 "참고 기준"으로 적음. 산업부·공단의 FEMS 보급사업 지침이나 KS 표준이 있다면 따로 받아야 함.
  • ISO 50001 원문: 유료라 보관되어 있지 않음. UMP 24장의 요약 설명만 씀.
  • 압축공기 누설에 대한 국내 공식 산정식: 공단 M&V 4.0과 2024 가이드라인에는 누설 보수 전용 식이 없음(통합제어·압축기 교체만 있음). EG-TIPS 「압축공기 SG03 v2.0」은 로그인 필요로 받지 못함(03 폴더 _목록.md). 그래서 누설 관련 값은 모두 DOE UMP 22장 기준이고 단위가 psig·SCFM임.
  • 펌프 인버터의 국내 표준 절감률: 공단 tool(경매 참고 ZIP 안)에 상사법칙 식이 있다는 기존 정리 노트(13번)가 있으나, 그 ZIP은 열지 말라는 지시에 따라 직접 확인하지 않았고 JSON에도 쓰지 않음.
  • 2024 가이드라인 p.3의 "ISO 50041" 표기는 표준 번호를 확인하지 못함(기존 정리 노트와 같음).
