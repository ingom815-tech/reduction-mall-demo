확인하지 못한 것 / 주의할 점

  1. IE4 효율 하한값 표: IEC 60034-30-1 본문 표는 유료라 확인 못 함. 그래서 "IE4 이상"이라는 기준만 적고 kW별 IE4 효율 수치는 넣지 않았음. 국내 최저소비효율기준 표(효율관리 별표 1)가 IE 몇 등급에 해당하는지도 원문에 적혀 있지 않아 연결 짓지 않았음.
  2. IE4 의무 여부: 국내 규정·지원사업 자료 어디에도 "IE4 이상이어야 지원"이라는 조건은 찾지 못함. KEA M&V 4.0(2021)은 프리미엄(IE3) 교체를 예로 들고 있음.
  3. 이코노마이저 단독 기준 없음: 고효율기자재·효율관리기자재 품목에 이코노마이저(급수예열기) 단독 품목은 없음. JSON의 배기가스 온도·열효율 수치는 "온수발생장치(배기가스 열회수 장치)가 붙은 고효율 가스 증기보일러" 인증 기준을 참고 기준으로 옮긴 것이고, 제품 설명에도 그렇게 적었음. 기존 보일러에 따로 붙이는 장치의 절감량 산정 방법(M&V)도 이번 자료에서는 찾지 못함(M&V 4.0의 보일러 항목은 보일러 교체 기준).
  4. '온수발생장치' = 이코노마이저?: 고시 원문 용어는 "배기가스 열을 회수하여 온수를 발생하는 장치"이고 '이코노마이저'라는 단어는 쓰지 않음. 같은 역할로 보고 연결했으나, 원문 표현이 다르다는 점은 남겨 둠.
  5. 고천장(하이베이) 전용 기준 없음: 고효율 인증 기준에는 '고천장'이나 '공장등'이라는 별도 구분이 없음. 실내용 LED등기구(KS C 7653 매입형·고정형, KS C 7657 센서등, KS C 7712 투광등) 기준을 적용했으며, 실제 제품이 어느 KS 분류에 들어가는지는 확인하지 않았음. 30W 초과 구간(110 lm/W)을 공장등에 맞는 구간으로 골랐음.
  6. LED와 녹색분류: 녹색분류체계 붙임9는 단순 보편화된 고효율기자재(LED 설비 등) 교체를 제외하므로, LED 공장등은 녹색분류 대상으로 소개하지 않는 게 맞음. 반대로 중기부 지원사업 목록에는 'LED조명'이 고효율 기기 예시로 들어 있음.
  7. S2 원본 URL: _목록.md에는 에너지공단 게시판 번호(boardNo=24614)만 있어 정확한 주소를 만들지 않고 localPath만 적었음.
  8. SRC-KEA-MV-2024(v2): 2.2 전동기 및 응용기기(PDF 16쪽, 인쇄 14쪽)에 "평균 소비전력과 연간 가동시간으로 절감량 산정"이 있으나, JSON에는 더 구체적인 M&V 4.0을 썼음. LED·보일러 열회수 항목은 v2에 없음.
  9. 열지 않은 파일: MOTIR_2026-039_..._예상절감량산정체계강화방안.zip, .xla 파일(지시대로 열지 않음).
