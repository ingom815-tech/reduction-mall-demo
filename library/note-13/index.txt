<h2>1. KEA M&amp;V 가이드라인 4.0 (2021)</h2>
<h3>1.1 개요·개정이력</h3>
<ul>
<li>판 이력: 1.0(2015, 최초 제정) → 2.0(2018.05, EERS 전기부문 23개 품목 표준절감량) → 3.0(2020.05, EERS 전기 17·가스 7·열 8개 품목, 표준절감량) → <strong>4.0(2021.07)</strong>.</li>
<li>4.0의 대상 품목은 17개임. 분류는 조명기기, 동력기기, 냉난방설비, 가전기기, 열손실 개선, 행동변화. 샘플링·조정·불확도 적용 예시는 4.0에서 새로 실렸음.</li>
<li>공단 공개자료실(2026-10 검색)에서 4.0보다 새 판은 찾지 못함. 2024년 효율시장 가이드라인이 사업별 후속 문서 역할을 함.</li>
<li>활용상 유의사항(원문 그대로 요약):<ul>
<li>절감량 보증이나 성과배분을 둘러싼 <strong>분쟁 시 근거자료로 쓸 수 없음</strong>.</li>
<li>상수·변수는 예시이므로 실측값을 적용해야 함.</li>
</ul>
</li>
<li>열량 기준(4.0): 최종에너지 기준 **총발열량(GCV)**을 씀. 전기 1 kWh = 860 kcal, 도시가스 1 Nm³ = 10,290 kcal(2017년 열량환산기준). 2022.11.21 개정 기준의 10,190 kcal보다 앞선 값임.</li>
</ul>
<h3>1.2 공통 방법론</h3>
<ul>
<li>절감량 = 베이스라인 에너지사용량 − 개선 후 에너지사용량 ± 조정량. 품목마다 이 틀을 똑같이 씀.</li>
<li>옵션 선택: 사업경계(개별설비 영향인지, 시설 전체 영향인지)와 측정 형태(일부 변수만 측정하는지, 전 변수를 측정하는지)로 A~D를 고름. 순서도에 &quot;예상 절감량 &gt; 사용량의 10%&quot;이면 옵션 C를 검토하는 분기가 있음.</li>
<li>샘플링(3장 4절, 품목별 &quot;바. 샘플링&quot;):<ul>
<li>무작위 샘플은 <strong>신뢰수준 80%·상대정밀도 ±20% 이내</strong>를 기본으로 함. 일반 설정은 90%/±10% 또는 80%/±20%.</li>
<li>초기 표본수 n₀ = (z·cv/e)². z는 95%일 때 1.96, 90%일 때 1.645, 80%일 때 1.28. 정보가 없으면 cv = 0.5를 씀.</li>
<li>추출률이 0.05를 넘으면 유한모집단 보정을 함: n = n₀·N/(n₀+N).</li>
<li>표본으로 cv를 다시 구한 뒤 최종 표본수를 정함.</li>
</ul>
</li>
<li>조정(3장 5절): 베이스라인 회귀모델로 조정 베이스라인을 만듦.<ul>
<li>유효성 기준: <strong>R² ≥ 0.75, t값 ≥ 2, CV &lt; 20%</strong>.</li>
<li>조정은 일상적 조정과 비일상적 조정으로 나뉨. 4.0은 일상적 조정을 중심으로 다룸.</li>
</ul>
</li>
<li>불확도(3장 6절):<ul>
<li>측정·샘플링·모델링·기타(비일상 조정·추정)의 4종으로 나눔. 총 불확도는 각 표준오차의 제곱합의 제곱근(RSS)임.</li>
<li>측정 불확도는 별도 조건이 없으면 신뢰수준 95%(1.96)를 씀. 정밀도가 주어지지 않으면 ISO/IEC Guide 98-3(GUM)을 따름.</li>
<li><strong>품목별 공통 요건: 산정 절감량은 베이스라인 에너지사용량 불확도의 2배 이상이어야 함.</strong></li>
<li>보고 시 신뢰수준과 정밀도를 함께 표기해야 함.</li>
</ul>
</li>
</ul>

<h2>2. 에너지효율시장 조성사업 설비별 에너지절감량 산정 가이드라인 v2 (2024)</h2>
<h3>2.1 체계</h3>
<ul>
<li>산정원칙: &quot;국제기준(ISO 50041, IPMVP) M&amp;V 일반원칙 준수&quot;. 원문 표기를 그대로 옮김. &quot;ISO 50041&quot;이라는 번호의 표준은 확인하지 못했으므로 오기일 가능성이 있음(미확인). M&amp;V 일반원칙은 정확성·완전성·보수성·일관성·관련성·투명성의 6가지임.</li>
<li>데이터:<ul>
<li>전력은 공단 <strong>EER 시스템이 15분 단위로 수집한 누적전력량</strong>을 씀.</li>
<li>영향인자는 4가지 방식으로 모음: 측정·자동수집, 관련변수 수집(일 단위 수기 양식), 정적인자 수집(최초 1회와 변경 시), 계산.</li>
</ul>
</li>
<li>산정 경계: 단독 운전 설비는 단일설비 경계를 씀. 시스템으로 묶여 운전되면 시스템 전체 경계를 씀. 예를 들어 여러 대 중 한 대만 교체해도 시스템 전체의 교체 전·후를 측정함.</li>
<li>옵션: <strong>일반적으로 옵션 A를 적용함.</strong> 에너지다소비 설비의 실시간 성능관리가 필요하면 <strong>옵션 B를 권장함.</strong></li>
<li>기간:<ul>
<li>베이스라인: <strong>주말 포함 최소 30일 이상 정상데이터, 설비 가동일수 20일 이상</strong>.</li>
<li>보고기간: <strong>교체 후 1년 이상 정상데이터</strong>.</li>
<li>2026 공고문: 유효데이터가 30일 미만이면 측정기간을 늘리고, 연간 부하변동을 포괄하도록 베이스라인을 정해야 함(예: 계절 부하가 다른 멀티EHP).</li>
</ul>
</li>
<li>운전특성값(표 4):<ul>
<li>EC_hr = 4 × (EC_t − EC_t−1): 15분 전력량의 4배를 시간당 전력량으로 봄.</li>
<li>평균소비전력 PC = ΣEC_hr,i / n.</li>
<li>부하율 = PC ÷ 정격용량.</li>
<li>가동시간 = 누적전력량 ÷ PC. 연간가동시간 = 일평균 가동시간 × 연간가동일수(주중·주말 구분).</li>
<li>누적값이 급증하거나 초기화(reset)되면 보정함.</li>
</ul>
</li>
<li>대상(2024년 기준 19개 지정품목)을 5개 유형과 기타로 나눔. 2026년 공고는 21개 품목임.<ul>
<li>공기압축기(단일·통합제어 시스템)</li>
<li>전동기·응용기기(삼상유도전동기, 인버터, 펌프, 송풍기, 터보압축기)</li>
<li>냉동기(스크류·원심식, 인버터 스크롤칠러)</li>
<li>히트펌프(수열 HP, 공기열 HP 온수기)</li>
<li>산업공정(덮개제어형 전기용해로, 고해기)</li>
</ul>
</li>
</ul>

<h3>2.3 계측전송장치 가이드라인 v1.2 요점</h3>
<ul>
<li>구성: 대상설비 → 전력량계 → RTU → 공단서버(EER). 전력량계는 설비당 1개가 원칙임.</li>
<li>전력량계: 한전 규격의 전자식, <strong>정밀도 1.0급</strong>. 15분 주기로 측정하고 <strong>60일 이상</strong> 저장함.</li>
<li>CT/PT: <strong>KS C 1707</strong> 준수, 인증 제품, 정밀도 1.0급(2024-03-14 수정).</li>
<li>통신비는 사업장이 부담함. 공단은 사업신청이 가능한 RTU 모델 목록을 공개함(2026-03 갱신).</li>
</ul>

<li>제16조: <strong>보증절감량은 목표절감량의 80% 이상</strong>으로 합의해 정함. 완료검사 후 합의한 방법으로 측정절감량을 산정하고 사용자 확인을 받음.</li>
<li>측정절감량이 보증절감량에 못 미치면 ESCO가 차액을 현금으로 보전함. 목표절감량을 넘으면 초과분을 합의 비율로 배분함.</li>
<li>평가 항목에 &quot;성과측정 및 검증(M&amp;V) 전문 자격 인력 보유&quot;가 있음.</li>
</ul>
</li>
<li><strong>ESCO협회 M&amp;V 계획서·결과보고서 양식</strong>(2023-01-11):<ul>
<li>계획서 목차: 개요(ESCO 표준계약서 붙임4 절감량 산출서 연계) → ECM 적용범위 → IPMVP 옵션과 측정경계(상호작용 효과) → 베이스라인(월별 사용량, 독립변수·정적인자, 운용조건) → 이후 항목.</li>
<li>결과보고서 양식도 함께 있음.</li>
</ul>
</li>
<li><strong>에너지효율시장 조성사업 운영지침·공고(2026)</strong>:<ul>
<li>계측전송장치를 구축하고, 개체 전 자체점검 결과보고서(별지 제8호)를 냄. 현장확인 → 베이스라인 30일 이상 → 공단 확인 후 개체 → 성과관리.</li>
<li>평가 항목에 &quot;M&amp;V(절감량산정) 계획 타당성 5점&quot;(방법론 적절성, 관련변수 수집·모니터링 방법)이 있음.</li>

</li>
<li><strong>중기부 탄소중립 설비투자 지원(2026)</strong>:<ul>
<li>지원설비에 <strong>적산전력계 등 계측장비 설치가 필수</strong>이고 비용은 기업이 부담함.</li>
<li>종료 후 <strong>5년간 감축 실적보고서</strong>를 냄. 실시설계 수행사가 감축실적 보고를 지원함.</li>

<h2>6. KEEI 수시연구 25-03 요지(2025)</h2>
<ul>
<li>국내 M&amp;V의 법적 기반은 EERS(수요관리 운영규정)와 ESCO 성과보증 조항이 간접적으로 제공함. M&amp;V를 독자적인 법적 실체로 두지 않음.</li>
<li>공단이 가이드라인을 주기적으로 냄(2015 → 2018 → 2020 → 2021 4.0 → 2024 설비별). 그러나 ESCO와 EERS의 M&amp;V가 따로 개발되어 **&quot;파편화&quot;**되어 있다고 봄.</li>
<li>가이드라인이 데이터가 없을 때 시뮬레이션 값이나 &quot;협의&quot;를 허용해 엄밀성이 부족하다고 지적함.</li>
<li>ESCO 설문:<ul>
<li>과반이 최근 5년간 M&amp;V 경험이 없음.</li>
<li>대부분이 엑셀 단순 계산이나 국내 가이드라인 수준임.</li>
<li>최대 장애요인은 비용과 외부요인(생산량·기후) 보정임.</li>
<li>결과 단계에서는 발주처가 성과를 인정하지 않는 문제가 가장 큼.</li>
</ul>
</li>
<li>제언: 한국형 표준 M&amp;V 가이드라인, 제3자 검증, M&amp;V 비용 지원, 입찰 가점, ESG·온실가스 실적 연계, 인력 양성.</li>
</ul>

<h2>7. Gaps(확보·확인 못 한 것)</h2>
<ul>
<li><strong>스팀트랩 교체·보수 절감량 공식 산식</strong>: 이번에 받은 국내 공식 문서(4.0, 2024 가이드, KEA tool 23종) 어디에도 없음. 외부사업 방법론 목록(ZIP)이나 DOE Steam Tip, UMP 등 해외 기준을 따로 검토해야 함.</li>
<li><strong>EERS 실적 검증 세부지침</strong>과 <strong>수요관리시책 에너지절감량산정 지침</strong>: 공개되지 않음. 정보공개청구 또는 공단 문의가 필요함.</li>
<li><strong>M&amp;V 가이드라인 3.0(2020, EERS 표준절감량)</strong>: 4.0 개정이력에서만 확인했고 게시물은 찾지 못함.</li>
<li><strong>EG-TIPS 설비시스템별 에너지절감량산출 가이드라인 7종(2015~2017)</strong>: 로그인이 필요해 받지 못함. 압축공기 SG03 v2.0, 펌핑 SG05, 히트펌프 SG06, 기기교체 SG04 v2.0과 산출방법 30종 등 상세 산식이 있을 가능성이 높으므로 사용자가 직접 받는 것을 권장함.</li>
<li>2024 가이드라인에 적힌 &quot;ISO 50041&quot;이라는 표준 번호를 확인하지 못함.</li>
<li>경매 [별지 제19호] 실적 산정기준은 &quot;별도 안내 예정&quot;이라고만 되어 있음. 2026-10 기준으로 안내문이 나왔는지 확인하지 못함.</li>
<li>배출권거래제 4차 계획기간의 GWP와 전력 배출계수 최신값이 공고 Tool 값(21/310, 0.4567 또는 0.4747)과 같은지 확인하지 못함.</li>
</ul>

<h2>8. 시스템 설계에 대한 시사점(추론)</h2>
<ul>
<li>산식 라이브러리는 2024 가이드라인 v2를 1차 기준으로 삼는 것이 적절함: ΔPC × Hrs, 1/COP 차이 × 생산열량, 원단위 × 생산량. 정규화 규칙은 R² ≥ 0.75, t ≥ 2, CV &lt; 20%이고, 불확도 판정은 4.0의 &quot;절감량 ≥ 2 × 베이스라인 불확도&quot;를 씀. 보일러·폐열·인버터 상사법칙은 KEA 산정tool 식으로 보완함.</li>
<li>데이터 모델은 2024 가이드 [붙임] 수집 양식(일 단위 EC, PC, Hrs, 관련변수, 정적인자)과 계측전송장치 사양(15분, 1.0급)에 맞춤. 경매 페널티 구간(90/70/50/150%)을 사후 모니터링 알림 규칙으로 넣음.</li>
<li>배출계수·GWP·열량계수는 <strong>지원사업별 프로파일</strong>로 분리해야 함(경매 0.4567, 중기부 0.4747 등). 공고 Tool과 결과가 같아야 심사·정산에서 다툼이 생기지 않음. 중기부 양식의 LNG·LPG 단위 표기 문제(천N㎥와 톤)를 입력 검증 단계에서 막아야 함.</li>
</ul>
