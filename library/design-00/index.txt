<p><strong>PPT 17장 &quot;크레딧이 될 수 있는 데이터 요건&quot;과 ③이 같은 것을 가리킴</strong></p>
<ul>
<li>PPT가 든 요건은 다섯 가지임: ①기준선(설치 전 사용량), ②측정 방식(인정 방법론에 맞게), ③기록 관리, ④권리 계약(데이터 활용 동의), ⑤중복 확인(정부 지원금 설비).</li>
<li>이 다섯 가지를 판정 항목으로 데이터에 넣으면, PPT의 MRV 전략과 1단계 시뮬레이션이 같은 기준으로 이어짐.</li>
</ul>

<ul>
<li>값</li>
<li>출처 ID</li>
<li>공식 원문 여부</li>
<li>확인일</li>
<li>다음 확인 예정일</li>
</ul>
<p>배출계수, 방법론, K-택소노미, 인증 품목은 매년 바뀌므로 <strong>연도별 기준 데이터</strong>로 관리하고 코드에 넣지 않음.</p>
<p><strong>판정 표현 규칙</strong></p>
<ul>
<li>&quot;해당 가능 / 조건 충족 시 가능 / 해당 없음&quot; 세 가지만 씀.</li>
<li>부족한 조건은 목록으로 보여줌.</li>
<li>&quot;인증됨&quot;, &quot;인정 완료&quot;, &quot;보장&quot;은 쓰지 않음. 최종 판단은 기관이 함 (PPT 22장 리스크 06과 같은 취지).</li>
</ul>

<h3>6-3. 공통 계산 구조</h3>
