1. 한 줄 정의

감축 투자를 판단하고, 실행하고, 증명하는 B2B 플랫폼. "제품을 파는 회사에서, 감축 성과를 관리하는 회사로." (PPT 2·25장)

2. 해결할 문제 (PPT 3장)

기업은 감축제품을 도입할 의지가 있어도, 다음 네 단계에서 막혀 투자를 미룸.

단계 막히는 이유 플랫폼의 답 (PPT 6장) 1단계 개발에서
선택 우리 업종·공정에 맞는 제품을 가려내기 어려움 업종·공정에 맞는 제품 추천 포함 (자동 추천)
판단 절감효과가 공급사 설명에 의존함 실제 사용량 기준 절감효과 계산 포함 (시뮬레이션 + 근거 데이터)
실행 구매·설치·지원사업을 따로 찾아야 함 견적·구매·설치·지원사업 연계 나중
증명 설치 후 실제로 얼마나 줄었는지 모름 MRV 성과관리 나중

1단계는 "선택"과 "판단"을 제대로 푸는 데 집중함. 특히 "판단" 단계는 공급사 말이 아니라 공식 근거가 붙은 숫자로 답하는 것이 핵심임.

3. 사업 구조 요약 (PPT)

항목 내용
추진 팀 영인에스티(쇼핑몰 운영·라이선스·영업 20명 이상·MRV 서비스) + 인포스퀘어(추천·계산·MRV 엔진, 플랫폼 기술)
연결 대상 파트너 제품기업 3~5곳, 구매기업, 제3자 검증기관
대상 고객 공공기관, 대기업·중견기업, 중소 제조기업. 1단계는 설비를 사려는 중소 제조기업 중심
6개 모듈 M1 추천·경제성 계산 / M2 공급사 입점 표준화 / M3 통합 판매 / M4 구매제품 MRV / M5 지원사업·컨설팅 / M6 영업·설치 유지관리
공통 기반 6개 모듈이 하나의 표준 제품 데이터를 같이 씀: 적용조건·성능·계산식·MRV 측정항목 (PPT 9장)
수익 제품 판매마진, MRV 구독료, 검증 연계·컨설팅 대가. 감축실적 거래 대행은 향후이며 사업성 판단에서 제외
MRV 이원화 중소기업은 저가로 "감축실적이 될 수 있는 데이터"를 쌓음. 중견·대기업은 검증기관 제출 패키지를 받음

4. 1단계 개발 범위

# 기능 관련 모듈 내용
1 제품 갤러리 M3 메인 화면에 제품 카드 4×4. 누르면 상세 페이지로 이동
2 상세 페이지 디자인 규격·레이아웃 M3 모든 제품이 같은 틀로 보이도록 영역과 순서를 고정
3 제품군별 표시 수치 M2 설비마다 핵심 성능 수치를 정함(아래 6장). 성적서와 연결
4 고객 회사 상황 입력 M1 업종, 에너지 사용량, 단가, 운전조건, 기존 설비. 간편 입력과 상세 입력
5 장바구니 시뮬레이션 M1 여러 제품을 담아 우리 회사에 적용한 효과를 제품별 결과와 합계로 보여줌
6 자동 추천 M1 고객 상황을 넣으면 효과가 큰 제품 순으로 추천
7 감축 근거·인정 기준 데이터 M1·M2 모든 감축 숫자의 분석 방법, 감축 기준, 공식 인정 가능 여부를 데이터로 보유

고객 흐름

제품부터 보는 고객:     [갤러리] → [상세 페이지] → 장바구니 담기 ─┐
                                                                ├→ [시뮬레이션 결과 + 근거 보기]
우리 회사부터 넣는 고객: [회사 상황 입력] → [자동 추천] ─────────┘
  • PPT 10장은 "홈페이지 주소 입력 → 업종 분석"으로 시작함. 1단계에서는 업종을 직접 고르게 하고, 주소 자동 분석은 나중으로 미룸. 이 부분은 결정이 필요함.

5. 신뢰의 핵심: 감축 근거 데이터 (3층 + 출처대장)

감축량 숫자만 보여주면 "공급사가 만든 숫자"로 보임. 그래서 숫자마다 아래 세 층의 근거를 데이터로 붙임.

층 담는 것 예 (인버터 공기압축기)
① 분석 방법 제품군별 계산식, 필요한 입력값, 근거 표준·방법론, 버전 비동력 비교법. 근거: IPMVP Option B
② 감축 기준 배출계수(연도), 기준선 규칙, 최소 측정기간, 배출 구분(Scope 1/2) 전력 0.4173 tCO2eq/MWh(2023년도 값). 설치 전 사용량을 기준선으로 함. Scope 2

PPT 17장 "크레딧이 될 수 있는 데이터 요건"과 ③이 같은 것을 가리킴

  • PPT가 든 요건은 다섯 가지임: ①기준선(설치 전 사용량), ②측정 방식(인정 방법론에 맞게), ③기록 관리, ④권리 계약(데이터 활용 동의), ⑤중복 확인(정부 지원금 설비).
  • 이 다섯 가지를 판정 항목으로 데이터에 넣으면, PPT의 MRV 전략과 1단계 시뮬레이션이 같은 기준으로 이어짐.

판정 표현 규칙

  • "해당 가능 / 조건 충족 시 가능 / 해당 없음" 세 가지만 씀.
  • 부족한 조건은 목록으로 보여줌.
  • "인증됨", "인정 완료", "보장"은 쓰지 않음. 최종 판단은 기관이 함 (PPT 22장 리스크 06과 같은 취지).

6-3. 공통 계산 구조

1단계: 줄어든 에너지 = 설비별 계산식(제품 성능값 + 고객 입력값)
2단계: 탄소감축량 = 줄어든 에너지 × 배출계수(연도 표시)
효과:  연간 절감액, 탄소감축량, 투자회수기간, 5년 누적
  • 제품 데이터에는 신규 설비 성능값이 들어감.
  • 고객 입력에는 기존 설비 값과 사용 조건이 들어감.
  • 모르는 칸은 업종 평균 같은 기본값으로 채우고 "추정값"으로 표시함.

9. PPT와 지금 정리의 차이 (조정할 점)

항목 PPT 지금 정리 조정안
시작 방식 홈페이지 주소로 업종 분석 갤러리 또는 회사 상황 입력 1단계는 업종 직접 선택, 주소 분석은 나중 (결정 필요)
