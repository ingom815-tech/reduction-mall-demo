1) 공장 지붕 자가소비형 태양광

  • SRC-KTAX-GUIDE-2025 녹색분류체계 가이드라인 1-나-(5) 태양광 기반 에너지 생산(인쇄 58쪽 / PDF 60쪽): "별도의 인정기준 미적용". 배제기준(수상태양광은 수도법 위생안전기준, 산지는 산지관리법)과 보호기준만 확인.
    • 참고로 인쇄 14쪽(PDF 16쪽) 배제기준 사례에 "태양광 부지 확보 시 대규모 토지 조성 과정에서 생태계 파괴"가 나옴. 지붕형에는 해당 가능성이 낮지만 데모 문구에는 넣지 않았음.
  • SRC-KTAX-HANDBOOK-2026 해설서 137~138쪽: 모듈·지지구조물·인버터·변압기를 구축·운영하는 활동이 해당하며, 부지·건물 임대만 하는 경우는 제외.
  • S6 신재생에너지센터 KS인증 안내(웹, 2026-10-21 열람): KS C 8561(결정질 실리콘 모듈), KS C 8562(박막 모듈), KS C 8565(태양광 인버터), KS C 8560(마이크로 인버터), KS C 8567(접속함), KS C 8577(BIPV). 각주에 "태양광, 태양열, 지열 인증의무화 2009년부터 시행중". 2015-07-29부터 KS인증제도로 전환함.
  • S5 GHG Protocol Scope 2 Guidance
    • 35~36쪽: 같은 회사가 자체 설비로 생산·소비하고 전력망과 주고받는 것이 없으면 Scope 2가 없고, 발전 배출은 Scope 1로 봄. 제3자가 소유·운영하는 현장 태양광은 사용자가 Scope 2로 보고.
    • 38쪽: 분산형 발전은 "총(gross) 구매량"으로 Scope 2를 계산해야 하며, 발전량과 상계한 순(net) 구매량을 쓰면 안 됨. 현장 발전 전력이라도 속성(인증서)을 팔았으면 Scope 2 배출로 봄.
  • S1 보고지침 제18조제6항: 재생에너지 전력의 간접배출 제외는 PPA·REC 구매·지분참여 등 구매 방식 4가지와 재생에너지 사용확인서 발급에 대한 조항입니다. 자가소비 태양광 전력을 국내 배출권거래제에서 어떻게 처리하는지 명시한 조항은 찾지 못했습니다. 그래서 JSON에는 이 조항을 태양광 근거로 쓰지 않았습니다.
  • SRC-GIR-EF-2025 2025년 승인 국가 온실가스 배출흡수계수 1쪽: 2023년도 소비단 CO2 0.4149 tCO2/MWh (CO2-eq 0.4173).

  • S1 보고지침 본문 제18조

    • 제3항: 화석연료와 혼합 사용 시 제16조에 따라 혼합비율을 산정해 그 비율만큼만 CO2 제외.
    • 제4항: 별표 10의 기본 배출계수(바이오매스) 활용 가능.
  • S2 [별표 16] 1~2쪽: 바이오매스 정의(신재생에너지법 제2조제2호바목). 고체연료 항목에 "땔감, 목재칩·펠릿·브리켓, 목탄, 가축분뇨 등". 석유제품 등과 섞여 구분이 안 되면 전체를 바이오매스에서 제외.

    • 2.19쪽, 표 2.3(제조업·건설업 고정연소): Wood/Wood Waste CO2 112,000(95,000132,000), CH4 30(10100), N2O 4(1.5~15) kg/TJ, 순발열량 기준.
  • SRC-KTAX-GUIDE-2025
    • 1-나-(12) 바이오에너지 기반 에너지 생산(인쇄 65쪽 / PDF 67쪽): 혼소 제외. 인정기준 가. 전력·열 생산량 대비 100 gCO2eq/kWh 이내(배출량은 배출권거래제 검증지침에 따라 산정), 나. 연료가 1-나-(1) 기준 충족.

2. 확인하지 못한 것 (JSON에 넣지 않음)

  1. 태양광 발전량 기준값: 지역별 일사량, 설비 이용률, 모듈 효율, 경년 열화율의 공식 수치를 받아 둔 자료에서 찾지 못함. 계산하려면 신재생에너지센터·한국에너지공단 공식 통계나 REC 가중치 고시 등을 따로 받아야 함.
  2. 자가소비 태양광의 국내 배출권거래제 처리: 보고지침 제18조제6항은 구매형 재생전력만 다룸. 자가소비 전력과 REC 판매를 함께 할 때 국내 명세서에서 어떻게 처리하는지 명시한 조항은 찾지 못함(GHG Protocol 기준만 확인).
  3. 고온(스팀용) 히트펌프 성능 기준: 고효율 인증은 공기-물, 20~200kW, 출수 45/55℃ 시험조건만 있고, 물 가열 전용·수열원 제품은 제외됨. 100℃ 넘는 온수·저압 스팀을 만드는 산업용 히트펌프의 공식 COP 기준이나 시험 표준은 찾지 못함. EG-TIPS 「SG06 히트펌프 v1.0(2017)」은 로그인이 필요해 받지 못한 상태(03 폴더 _목록.md).
  4. MSS 지원사업에서 히트펌프의 유형: 신재생에너지형 "폐열회수 이용설비"에 들어가는지 공고문에 명시되지 않음.
  5. 산업용 대형 목재펠릿 보일러 인증 기준: KS B 8901 시험기관 안내는 58.14kW 이하. 그보다 큰 산업용 보일러의 효율 기준은 찾지 못함. KS B 8901 본문(효율 기준값)은 유료 표준이라 확인하지 않음.
  6. 목재펠릿 발열량·국가 고유 배출계수: [별표 12] 연료별 국가 고유 발열량에서 목재펠릿 값은 이번에 확인하지 않음. 필요하면 별표 10·12를 다시 볼 것.
  7. 신재생에너지법·시행령 원문: law.go.kr 조회가 자동 요청으로 되지 않아 직접 받지 못함. 바이오매스·바이오에너지 정의는 보고지침 [별표 16]이 법 제2조와 시행령 [별표 1]을 인용한 부분으로 갈음함.
  8. S4 원본 URL: 공단 게시판이 POST 방식(View2.do, boardNo=24614, fileNo=24541, fileSeq=2)이라 JSON에는 URL을 넣지 않고 localPath만 적음.

  • 새로 만든 출처: S1(보고지침 본문 제18조), S2(보고지침 별표 16), S3(고효율 규정 별표 2), S4(KEA 2026 지정설비 21개 품목), S5(GHG Protocol Scope 2 Guidance), S6(신재생에너지센터 KS인증 안내 웹페이지).
  • 사이트에 넣을 때 S1~S6은 사이트 ID 규칙(SRC-…)으로 바꿔야 함. S6은 웹페이지라 열람일(2026-10-21)을 checkedDate로 넣을 것.
