<h2>Q1. IPMVP(EVO) Core Concepts 2022 및 EVO 적용가이드 (옵션 A–D, 불확도)</h2>
<h3>Takeaway</h3>
<p>IPMVP의 현행판은 <strong>IPMVP Core Concepts 2022</strong>(EVO)이며, 2026-10 기준 더 새로운 판은 확인되지 않음. EVO 웹계정 로그인 후 Library에서 내려받을 수 있음(무료 계정 여부는 페이지에 명시 없음). 불확도는 별도 가이드 <strong>EVO 10100-1:2018 (Uncertainty Assessment)</strong>, 비정상 사건은 <strong>IPMVP Application Guide on Non-Routine Events &amp; Adjustments (2020-10)</strong> 가 담당함.</p>
<h3>Cited Findings</h3>
<ul>
<li>EVO는 IPMVP 25주년에 맞춰 <strong>IPMVP Core Concepts 2022</strong>를 발표함. 5년 주기 법정 검토를 거친 개정판임 — <a href="https://evo-world.org/en/news-media/evo-news/1280-release-of-the-new-ipmvp-core-concepts-2022" target="_blank" rel="noreferrer">EVO 뉴스: Release of the new IPMVP Core Concepts 2022</a></li>
<li>2022 개정에서 <em>IPMVP Issues and Examples 2016</em> 적용가이드 내용 상당 부분을 흡수함. M&amp;V 통계, Advanced M&amp;V, 에너지성과계약(EPC) 내용을 추가함. 옵션 선택 기준을 명확히 하고 M&amp;V 계획·보고 요구사항을 추가함 — <a href="https://evo-world.org/en/news-media/evo-news/1280-release-of-the-new-ipmvp-core-concepts-2022" target="_blank" rel="noreferrer">EVO 뉴스</a>; <a href="https://globalesconetwork.unepccc.org/events/release-of-the-2022-ipmvp-core-concepts-highlights/" target="_blank" rel="noreferrer">UNEP CCC 행사 안내 (2차 자료)</a></li>
<li>다운로드: EVO 웹계정으로 로그인한 뒤 Library에서 받음. 구판은 Archives 폴더에 있음. 계정이 무료인지 유료 회원 전용인지는 페이지에 명시되지 않음 — <a href="https://evo-world.org/en/library/download-protocol-documents-mainmenu-en" target="_blank" rel="noreferrer">EVO Library: IPMVP Documents</a></li>
<li>프랑스어판 PDF(IPMVP 2022, 2023-03-13 최종본)에 &quot;©2022-2025&quot; 저작권 표기가 있음. 저작권 기간 표기일 뿐 신판의 증거는 아님 — <a href="https://atee.fr/system/files/2026-01/IPMVP%202022_FINAL_03.13.23_FR.pdf" target="_blank" rel="noreferrer">ATEE 호스팅 FR PDF (2차 자료)</a></li>
<li>옵션 체계: A·B는 개체분리(Retrofit Isolation), C는 전체시설(Whole Facility), D는 보정 시뮬레이션(Calibrated Simulation). 아래 FEMP 5.0 요약도 같은 옵션 정의를 씀:<ul>
<li><strong>A(핵심변수 측정)</strong>: 용량·효율 같은 핵심 변수만 측정하고 나머지는 추정함. 추정치의 불확도가 클 수 있음. 조명 개체에 적합함.</li>
<li><strong>B(전 변수 측정)</strong>: 단기 또는 연속 계측으로 모든 변수를 측정함.</li>
<li><strong>C(전체시설)</strong>: 유틸리티 고지서나 계량기 데이터로 회귀분석함. 절감량이 전체 사용량의 약 10~15%를 넘을 때 적합함.</li>
<li><strong>D(보정 시뮬레이션)</strong>: 최소 12개월 고지서로 보정함.</li>
<li>출처 — <a href="https://www.energy.gov/sites/default/files/2024-10/mv_guide_5_0.pdf" target="_blank" rel="noreferrer">DOE FEMP M&amp;V Guidelines 5.0 (2024-09), Table 4-1 및 4.2~4.5절</a></li>
</ul>
</li>
<li><strong>EVO 10100-1:2018 Uncertainty Assessment</strong> 가이드는 오차원을 모델링·샘플링·측정 3가지로 나누고 각각의 정량화 방법을 제시함 — <a href="https://evo-world.org/images/corporate_documents/Evo-Guides_Family-v05-12mars2019-page-low-res.pdf" target="_blank" rel="noreferrer">EVO Guides Family 브로셔 (2019)</a>; 검색요약 기준 (2차 자료)</li>
<li><strong>IPMVP Application Guide on Non-Routine Events &amp; Adjustments</strong>는 2020-10 발표됨. 회귀 기반 에너지모델 M&amp;V에서 NRE(정적요인 변화)와 NRA(비정상 조정)를 다룸 — <a href="https://www.evo-world.org/images/denisdocuments/PR_2020-1027_NRE_FINAL.pdf" target="_blank" rel="noreferrer">EVO 보도자료 PR_2020-1027_NRE</a>; <a href="https://evo-world.org/br/news-media/evo-news/1195-release-of-the-ipmvp-application-guide-on-non-routine-events-and-adjustments" target="_blank" rel="noreferrer">EVO 뉴스 1195</a></li>
<li>EVO M&amp;V Focus #6(2020-05)은 Advanced(미터 기반) M&amp;V 가이드를 개발 중이라고 밝힘. 시간·일 단위 데이터에서는 기존 FSU(Fractional Savings Uncertainty) 계산이 불확도를 과소추정한다고 지적함 — <a href="https://evo-world.org/br/news-media/m-v-focus/882-may-2020-m-v-focus-issue-6/1184-advanced-measurement-verification-and-ipmvp" target="_blank" rel="noreferrer">EVO M&amp;V Focus Issue #6</a></li>
<li>2024년 UNEP CCC 국제 ESCO 심포지엄 자료에는 불확도·Advanced M&amp;V 가이드의 발간 일정이 2024년 하반기로 적혀 있음. 실제 발간 여부는 확인하지 못함 — <a href="https://c2e2.unepccc.org/wp-content/uploads/sites/3/2024/07/international-esco-symposium-2024-measurement-and-verification-in-performance-contracts.pdf" target="_blank" rel="noreferrer">UNEP CCC International ESCO Symposium 2024 자료 (2차 자료)</a></li>
<li>EVO Programs 브로셔(2022)는 Core Concepts 2022를 현행 프로토콜로 소개함. 다른 적용가이드는 개정 또는 준비 중으로 표기함 — <a href="https://evo-world.org/images/corporate_documents/EVO_PROGRAMS_2022_EN_v03.pdf" target="_blank" rel="noreferrer">EVO PROGRAMS 2022</a></li>
</ul>
<h3>Inferences</h3>
<ul>
<li>시스템의 &quot;절감량 검증&quot; 로직은 IPMVP 2022 옵션 체계를 상위 프레임으로 두는 것이 적절함. 통계 기준(CV(RMSE), NMBE, FSU)은 ASHRAE G14-2023을, 설비별 적용 예시는 FEMP 5.0과 UMP를 하위 규칙으로 쓰는 계층 구조가 합리적임.</li>
<li>생산량이나 기상으로 정규화하는 회귀 기준선을 쓴다면 NRE/NRA 가이드(2020)의 &quot;정적요인 변화 시 조정&quot; 로직을 반영해야 함. 설비 증설이나 제품 믹스 변경이 여기에 해당함.</li>
</ul>
<h3>Gaps</h3>
<ul>
<li>IPMVP Core Concepts 2022 이후의 신판(2025~2026) 존재 여부: EVO 뉴스·Library에서 확인되지 않음. EVO Library에 로그인해 직접 확인할 필요가 있음.</li>
<li>EVO 무료 계정만으로 Core Concepts를 받을 수 있는지, 유료 회원 전용인지 명시된 근거를 찾지 못함.</li>
<li>Core Concepts 2022 본문의 최소 측정기간, 불확도 보고 의무 문구를 원문으로 확인하지 못함(PDF 미열람).</li>
<li>2024년 이후 발간된 EVO 적용가이드(Advanced M&amp;V, Uncertainty 개정판, Sampling 등)의 정확한 제목과 연도는 미확인.</li>
</ul>

<h2>Q2. ISO 50001/50006/50015/50047/50046/17741, ASHRAE Guideline 14-2023, DOE FEMP M&amp;V Guidelines, DOE UMP</h2>
<h3>Takeaway</h3>
<ul>
<li>ISO 50001의 현행본은 **ISO 50001:2018 + Amd 1:2024(Climate action changes)**임. 신판 개정 착수와 진행 단계는 확인하지 못함.</li>
<li>FEMP는 **M&amp;V Guidelines 5.0(2024-09)**을 발간해 4.0(2015-11)을 대체했음. 무료임.</li>
<li>ASHRAE Guideline 14-2023은 유료임. 2024 errata로 회귀모델 순편향(NDB) ≤0.5%가 정해졌고, 2025-10-29 Addendum a가 승인됨.</li>
<li>DOE UMP는 프로토콜 24개를 무료로 제공함. 압축공기 프로토콜은 2021-01 개정됨.</li>
</ul>
<h3>Cited Findings</h3>
<p><strong>ISO 계열</strong></p>

<h2>Q6. 한국 에너지진단 기준 및 ESCO·EERS 성과측정(M&amp;V) 공식 가이드라인</h2>
<h3>Takeaway</h3>
<p>한국에는 단일 국가 M&amp;V 표준이 없음. 한국에너지공단의 **「에너지효율 투자 및 지원사업 성과 측정검증 가이드라인 4.0」(2021, 17개 품목)**과 **「에너지효율시장 조성사업 설비별 에너지절감량 산정 가이드라인」(2024, 압축공기·전동기 및 응용기기·냉동·물-물/공기-물 히트펌프·산업공정 5개 설비)**이 사실상의 공식 절감량 산정 기준임. ESCO협회가 M&amp;V 계획서·결과보고서 양식과 가이드를 냄. 법적 근거는 에너지이용 합리화법 제9조(EERS)와 제25조(ESCO)이고, 하위 규정 「에너지공급자의 수요관리 투자사업 운영규정」·「에너지절약전문기업 관리규정」으로 구체화됨.</p>
<h3>Cited Findings</h3>
<ul>
<li>에너지경제연구원 수시연구보고서 25-03, 『에너지효율사업의 성과 측정 및 검증(M&amp;V) 제도 고도화 방안 연구』(소진영, 2025; 한국에너지공단·ESCO협회 자문) — <a href="https://www.keei.re.kr/pdfOpen.es?bid=0001&amp;list_no=126670&amp;seq=1" target="_blank" rel="noreferrer">KEEI PDF</a>:<ul>
<li>법적 기반: 에너지이용 합리화법 제9조(에너지공급자의 수요관리투자계획)·시행령 제16조가 EERS의 근거, 제25조·시행령 제30조가 ESCO의 근거임. M&amp;V는 법에 직접 명시되지 않고 EERS·ESCO 성과보증계약을 통해 간접적으로 요구됨.</li>
<li>하위 규정: 「에너지공급자의 수요관리 투자사업 운영규정」, 「에너지절약전문기업 관리규정」(보고서 작성 당시 산업통상자원부 고시, 검색일 2025-10-15).</li>
<li>한국에너지공단은 2015년 M&amp;V 절감량 산정 가이드라인을 처음 만들고 2018·2020년에 개정함. 2021년에 <strong>「에너지효율 투자 및 지원사업 성과 측정검증 가이드라인 4.0」</strong>(산업통상자원부·한국에너지공단, 2021)을 냄. 조명기기·동력기기·냉난방설비·가전기기·열손실 개선·행동변화로 나눠 <strong>17개 품목</strong>의 절감량 산정 방법론을 제시함.</li>
<li>2024년 한국에너지공단은 **「에너지효율시장 조성사업의 설비별 에너지절감량 산정 가이드라인」**을 발간함. 보고서는 &quot;ISO 50041&quot;, IPMVP 등 국제기준의 일반원칙을 준수했다고 적음. 대상 설비는 압축공기시스템, 전동기 및 응용기기, 냉동시스템, 물-물 및 공기-물 히트펌프, 산업공정 설비 5개.</li>
<li>한국에너지공단 EG-TIPS(에너지온실가스종합정보 플랫폼)에 &#39;에너지절감산출 M&amp;V&#39; 섹션이 있음.</li>
<li>ESCO협회: M&amp;V 계획서 양식, IPMVP 기반 M&amp;V 계획서 작성 가이드라인, M&amp;V 결과보고서 양식을 냄(2025-07-10 자료 인용).</li>
<li>한계: 사업별 지침이 따로 존재해(ESCO와 EERS) 일관성이 부족함. 데이터가 없으면 시뮬레이션이나 사업자 &quot;협의&quot;를 허용하는 등 엄밀성이 부족함. 통합 국가 M&amp;V 가이드라인이 없음.</li>
</ul>
